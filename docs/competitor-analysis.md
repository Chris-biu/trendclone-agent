# TrendClone Agent 竞品分析

## 1. 分析结论

当前 AI 视频工具大多集中在三类能力：

1. 生成素材：根据文本、图片或视频生成新视频。
2. 剪辑执行：模板、字幕、剪辑、配音、发布素材处理。
3. 灵感发现：查看热点、模板、案例或热门内容。

TrendClone Agent 的差异化空间在于：

> 把“看到爆款视频”到“生成自己的同款原创视频方案”之间的创意拆解、结构迁移和风险控制产品化。

也就是说，它不是替代可灵、Runway、剪映，而是作为它们前面的创意 Agent。

## 2. 竞品矩阵

| 产品 | 核心能力 | 强项 | 不足 | TrendClone 的机会 |
|---|---|---|---|---|
| 剪映 / CapCut | 剪辑、模板、字幕、AI 视频生成 | 生产链路成熟，适合普通用户剪辑和发布 | 更偏执行工具，用户仍要自己判断爆款结构 | 提供前置的爆款拆解和同款脚本 |
| 可灵 / Kling | 文生视频、图生视频、多模态视频生成 | 生成质量强，适合做 AI 视频片段 | 主要解决“生成画面”，不负责判断什么创意会火 | 输出可直接用于可灵的分镜提示词 |
| Runway | 专业级视频生成 API 和创意工具 | API 和模型能力成熟，适合开发者集成 | 成本和使用门槛较高，普通用户仍需会写提示词 | 将复杂提示词产品化、结构化 |
| 即梦 | 中文 AI 图像/视频创作 | 中文内容生态和上手门槛较友好 | 仍偏素材生成，缺少爆款结构分析 | 输出平台化创意方案和风险评估 |
| 抖音/小红书热点内容 | 热点和爆款样本 | 能看到真实流行内容 | 不告诉用户“为什么火”以及“怎么改成自己的” | 自动提炼爆款公式和改编路径 |
| Coze/Dify 类 Agent 平台 | 搭建 Agent 工作流 | 适合快速做自动化流程 | 不是垂直短视频创意产品 | TrendClone 是垂直场景产品 |

## 3. 竞品拆解

### 3.1 剪映 / CapCut

定位：普通用户和内容创作者的视频编辑与发布工具。

强项：

- 剪辑链路成熟。
- 有字幕、模板、特效、配音等能力。
- 官方 CapCut 页面展示了 AI video generator 等创作入口。

弱点：

- 用户仍需要自己决定选题和创意结构。
- 模板可以降低制作门槛，但无法解释爆款为什么有效。
- 对“同款但原创”的风险控制不足。

TrendClone 切入点：

- 在进入剪辑前，先输出脚本、分镜、提示词和发布文案。
- 把爆款结构转成可编辑的制作包，再交给剪映执行。

### 3.2 可灵 / Kling

定位：AI 视频生成模型和创作平台。

强项：

- 适合生成 AI 视频片段。
- Kling 官方/开发者文档展示了视频生成 API 接入方向。
- 快手公开材料中强调可灵 3.0 支持文本、图像、音频、视频的多模态输入输出和视频理解/生成/编辑一体化。

弱点：

- 用户需要知道生成什么。
- 用户需要写高质量提示词。
- 不负责判断参考爆款的结构是否适合迁移。

TrendClone 切入点：

- 把参考爆款拆成逐镜头提示词。
- 输出负向约束，避免出现原视频专属元素。
- 作为可灵前置的创意规划层。

### 3.3 Runway

定位：面向创作者和开发者的 AI 视频生成平台。

强项：

- Runway 官方 API 文档显示可通过 API 创建视频生成任务。
- 官方模型页面展示了文本/图片到视频等模型能力。
- 适合 V3 阶段接入，生成真实视频片段。

弱点：

- API 成本和集成门槛较高。
- 对中文短视频平台内容生态的适配需要产品层补足。
- 用户仍然要自己完成爆款分析和分镜规划。

TrendClone 切入点：

- 先生成结构化分镜，再调用 Runway。
- 把 Runway 作为执行层，不把它当作完整竞品。

### 3.4 即梦

定位：中文 AI 图像和视频创作工具。

强项：

- 中文内容生成和视觉创作更贴近国内用户。
- 适合普通创作者上手。

弱点：

- 仍然偏“输入提示词生成素材”。
- 用户需要自己完成创意策略和内容复盘。

TrendClone 切入点：

- 给出更明确的同款脚本、分镜和提示词。
- 针对抖音、小红书、视频号输出不同平台文案。

## 4. 用户为什么不直接用现有工具

因为用户真实卡点不是“没有生成工具”，而是：

- 不知道今天什么形式值得跟。
- 不知道爆款视频为什么火。
- 不知道哪些元素能复用，哪些元素不能复用。
- 不知道如何把别人的爆款结构迁移到自己的产品或账号。
- 不知道怎么写逐镜头提示词。
- 不知道做得太像会不会有风险。

TrendClone Agent 的价值是：

> 从爆款样本里提炼创意结构，再生成适合用户自己主题的原创制作包。

## 5. 产品差异化

| 维度 | 普通 AI 视频生成工具 | TrendClone Agent |
|---|---|---|
| 输入 | 提示词、图片、素材 | 爆款参考 + 自己的改编目标 |
| 输出 | 视频或图片素材 | 拆解报告、脚本、分镜、提示词、文案、风险评分 |
| 核心能力 | 生成画面 | 理解爆款结构并迁移 |
| 用户心智 | 帮我生成视频 | 帮我做一个同款但原创的视频方案 |
| 风险控制 | 较弱 | 明确提示相似度和原创风险 |
| 简历亮点 | 调 API | 产品流程、Agent 工作流、评测指标、合规边界 |
