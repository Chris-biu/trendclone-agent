# TrendClone Agent 评测报告 V0.1

## 评测目标

本报告用于评估 TrendClone Agent 生成“爆款结构复刻与原创改编方案”的质量。评测重点不是模型回答是否流畅，而是生成结果是否能进入真实短视频制作流程。

## 评测指标

| 指标 | 说明 | 目标 |
|---|---|---|
| 结构复刻度 | 是否识别并保留参考视频的钩子、节奏和叙事顺序 | 75+ |
| 原创安全分 | 是否避开原视频人物、音乐、完整台词、品牌/IP 和构图 | 75+ |
| 平台适配度 | 是否符合抖音、小红书、视频号或 B 站的平台节奏 | 80+ |
| 提示词可用性 | 分镜提示词是否具体到可以交给视频生成工具 | 80+ |
| 制作难度 | 镜头数量、素材复杂度和时长是否可控 | 70+ |
| 脚本可发布度 | 是否包含开头、过程、结果和行动引导 | 80+ |

## 当前样本库

当前内置 6 条示例样本，覆盖：

- AI 老照片动起来
- 普通产品拍成高级广告片
- 生活小事电影预告片
- 三步 AI 视频教程
- 宠物拟人大片
- AI 新闻播报

## 当前结论

V0.1 已经具备基础评测闭环：

```text
样本选择
-> 自动填充参考结构
-> 生成创意包
-> 输出三版本方案
-> 输出 6 项评测指标
```

下一步需要把样本库扩展到 20 条，并记录每条样本生成后的人工评分，形成可量化迭代记录。

## 迭代记录

| 版本 | 变化 | 评测意义 |
|---|---|---|
| V1 | 前端规则生成创意包 | 验证产品流程 |
| V2 | 增加 Node API 和大模型接口 | 支持真实 Agent 输出 |
| V2.1 | 增加三版本方案和评测面板 | 支持方案选择和质量评估 |
| V2.2 | 增加样本库和多页面导航 | 支持爆款公式沉淀和更清晰的用户路径 |
