# TrendClone Agent 产品需求文档 V1

## 1. 产品定位

TrendClone Agent 是一个面向 AI 视频创作者、短视频运营和小商家的爆款视频结构复刻与原创改编工具。

用户上传或描述一个爆款参考视频，再输入自己的产品、账号或主题，Agent 自动拆解参考视频的爆款结构，并生成可制作的同款原创创意包，包括脚本、分镜、AI 视频提示词、发布文案、成片预览和原创风险提示。

产品重点不是直接搬运爆款视频，而是帮助用户复用爆款的叙事结构、节奏和创意公式，同时替换人物、台词、画面、品牌、音乐等高风险元素。

## 2. 目标用户

| 用户类型 | 典型需求 | 当前痛点 |
|---|---|---|
| AI 视频创作者 | 快速追热点，做同款 AI 视频 | 看到爆款但不知道如何拆结构 |
| 短视频运营实习生 | 为产品或账号产出选题和脚本 | 创意产能不足，脚本质量不稳定 |
| 小商家/校园创业团队 | 用短视频推广产品或活动 | 不会写脚本，也不会用 AI 视频工具 |
| 自媒体新手 | 学习爆款套路并迁移到自己账号 | 容易照抄，存在原创和平台风险 |

## 3. 核心场景

用户刷到一个热门 AI 视频，觉得形式很好，但不知道：

- 这个视频为什么可能会火
- 它的开头钩子、节奏、转折点在哪里
- 自己的产品或主题能不能套用这个结构
- 如何生成同款但不直接搬运
- 如何写提示词给可灵、Runway、即梦等视频生成工具
- 如何判断原创风险

TrendClone Agent 把这个过程产品化为：

```text
爆款参考输入
-> Agent 结构拆解
-> 同款原创改编
-> 动态分镜规划
-> AI 视频提示词
-> 发布文案
-> 原创风险检测
-> 成片预览/导出制作包
```

## 4. V1 功能范围

### 4.1 输入模块

用户可以输入：

- 本地参考视频文件
- 视频链接
- 视频文案、字幕或观察记录
- 要推广的产品、账号或主题
- 目标人群
- 发布平台
- 视频时长
- 结构贴近度
- 镜头数量：AI 自动判断或手动指定

V1 中上传视频暂不做真实内容解析，只读取文件信息；真实视频解析放到 V2。

### 4.2 爆款结构拆解

Agent 输出：

- 开头钩子
- 叙事节奏
- 情绪价值
- 可复刻边界

每个维度包含一句总结和一段解释，帮助用户理解参考视频的可迁移结构。

### 4.3 动态镜头规划

Agent 根据以下因素自动判断镜头数：

- 视频时长
- 参考描述里的节奏词，如快切、转场、对比、教程、步骤、反转
- 平台风格，如抖音/小红书更偏快节奏
- 结构贴近度
- 内容类型，如教程拆解型需要更多步骤镜头

输出包括：

- 镜头数量
- 判断理由
- 每个镜头的标题、画面、字幕、旁白和 AI 视频提示词

### 4.4 同款原创脚本

Agent 生成按时间段拆分的短视频脚本：

- 0-3 秒钩子
- 中段过程展示
- 主题替换
- 结果展示
- CTA

### 4.5 AI 视频提示词

每个镜头输出适合视频生成工具的提示词，默认包含：

- 竖屏 9:16
- 画面主体
- 镜头运动
- 中文短视频质感
- 负向约束：避免知名品牌、真实名人、原视频专属元素

### 4.6 成片预览

V1 提供模拟成片预览：

- 手机竖屏框
- 视频标题/字幕
- 镜头生成队列
- 模拟合成状态

V1 不直接输出 MP4，V3 再接视频生成 API 和合成服务。

### 4.7 发布文案

按平台输出：

- 视频标题
- 封面文案
- 正文
- 话题标签
- 评论区引导

### 4.8 原创风险检测

风险分为：

- 高风险：复用画面、音乐、完整台词、人物/IP/品牌
- 中风险：构图、镜头顺序过度相似
- 低风险：复用叙事结构、节奏和内容公式

输出原创安全分，帮助用户控制“像爆款”和“像搬运”之间的边界。

## 5. 用户流程

1. 用户上传参考视频或粘贴视频链接。
2. 用户补充视频文案、字幕或自己的观察。
3. 用户填写自己的推广目标和目标人群。
4. 用户选择发布平台和视频时长。
5. 用户保留默认“AI 自动判断镜头数”。
6. 用户点击生成。
7. Agent 输出爆款拆解、脚本、分镜、提示词、发布文案和风险检测。
8. 用户点击模拟合成查看成片预览。
9. 用户导出 JSON 制作包，交给可灵、Runway、即梦或剪映继续生成视频。

## 6. 核心指标

| 指标 | 定义 | V1 目标 |
|---|---|---|
| 生成完成率 | 点击生成后成功输出完整创意包的比例 | 95%+ |
| 脚本可用率 | 用户认为脚本可以继续修改使用的比例 | 70%+ |
| 分镜完整率 | 每个镜头都有画面、字幕、提示词 | 100% |
| 原创安全分 | 系统对过度相似风险的评估分 | 默认 70+ |
| 用户采纳率 | 用户导出 JSON 或复制报告的比例 | 30%+ |
| 修改负担 | 用户生成后需要大改的地方数量 | 逐轮下降 |

## 7. V2 规划

V2 重点从“静态原型”升级为“真实 Agent 工作流”：

- 自动抽取视频关键帧
- OCR 识别画面文字
- ASR 识别旁白和字幕
- 基于关键帧和字幕生成结构拆解
- 支持高相似版、低风险版、平台适配版三种方案
- 支持样本库沉淀和案例复用

## 8. V3 规划

V3 输出完整 MP4：

```text
分镜提示词
-> 调用视频生成 API 生成片段
-> 旁白 TTS
-> 字幕生成
-> FFmpeg 拼接
-> 导出竖屏 MP4
```

可选 API/工具：

- Runway API：官方文档显示支持视频生成 API 和 SDK。
- Kling/可灵 API：可用于视频生成接入，但需要确认具体服务、费用和权限。
- FFmpeg：用于本地拼接视频、加字幕、合成音频。

## 9. 风险与边界

| 风险 | 说明 | 产品策略 |
|---|---|---|
| 搬运/侵权 | 过度复用原视频画面、音乐、台词 | 强制输出风险提示和替换建议 |
| 平台风控 | 内容过度相似可能被限流或投诉 | 提供原创安全分 |
| 生成质量不稳定 | 视频生成模型可能不稳定 | V1 先输出制作包，不直接承诺成片 |
| 成本过高 | 视频生成 API 成本高 | V1/V2 先做提示词和流程，V3 再接 API |
| 数据获取合规 | 自动抓取平台视频有风险 | MVP 采用用户上传/手动录入 |

## 10. 当前 Demo 状态

已完成：

- 静态 Web Demo
- Node 本地服务
- `/api/generate` Agent 生成接口
- OpenAI-compatible 大模型接入配置
- 无 API Key 时的本地回退生成器
- 结构化 JSON Schema 归一化
- 输入面板
- 动态镜头数判断
- 分镜与提示词生成
- 成片模拟预览
- JSON 导出
- 风险检测

未完成：

- 自动视频解析
- 视频生成 API
- MP4 合成导出
- 用户账号和历史案例管理

配置真实大模型需要在 `.env` 中设置 `AI_API_KEY`、`AI_API_BASE_URL` 和 `AI_MODEL`。未配置时，系统会自动使用本地回退生成器，保证演示流程可用。
